# Wok & More - Storyboard App

A Flutter application showcasing a 20-second street cooking video script for "Wok & More". The app features a dark, fiery aesthetic matching the street food vibe, presenting the script in a clear timeline format complete with visual directions and voiceover copy.

## Features
- **Responsive Timeline Layout**: Works on mobile, tablet, desktop, and web preview environments.
- **Script Cards**: Clearly separated visual directions and voiceover sections with distinct typography and icons.
- **Fiery UI Theme**: Dark mode styled with deep oranges and ambers reflecting the wok fire theme.
- **Footer Notes**: Built-in section for music and sound effect cues.

## Getting Started

1. Ensure you have Flutter installed.
2. Clone the repository and navigate to the project directory.
3. Run `flutter pub get` to fetch dependencies.
4. Run the app using `flutter run` on your preferred device or emulator.
